# Проверка установочного комплекта

Дата повторной проверки Сферы: 06.10.2026. Рабочий VPS не изменялся. Действующие репозитории не изменялись.
Для подготовки выполнены только чтение исходников и schema-only экспорт определений.

Проверено на отдельной PostgreSQL 16.14 на ноутбуке и Python 3.12:

- восстановление всех схем на пустой базе и нейтральный seed;
- нулевые начальные таблицы бизнес-знаний, сообщений и задач;
- новые account/project UUID;
- создание пользователей и запрет повторной инициализации непустой базы;
- вход, отказ при CSRF и открытом redirect;
- OAuth, неправильный PKCE, одноразовый authorization code;
- owner identity и получение нейтрального контекста/навыков;
- reader scopes и отказ в создании задачи;
- чтение настоящей созданной задачи владельцем и отказ другому пользователю;
- запись Markdown с журналом версий и отказ при устаревшем SHA;
- структурированный finish_task и постановка обработки в очередь;
- чтение UI-графа/документов и ограничение чужих задач;
- отказ отключённому пользователю, ротация refresh и отзыв семейства при replay;
- запрет чтения хешей паролей ролью MCP;
- синтаксис Python, Compose config и отсутствие рабочих секретов в Git.

Итог: 30 функциональных проверок, подробности — TEST_RESULTS.json.
Файловая блокировка Linux в Windows-проверке заменена однопроцессным тестовым
адаптером; её конкурентные свойства этим прогоном не доказаны.

Остаются: полноценный Docker build/up на чистом Linux, TLS Caddy, браузерный
визуальный прогон, запуск моделей, Qdrant/Neo4j-проекции и восстановление backup.
Docker Desktop на ноутбуке не предоставил Linux engine; боевой VPS для тестового
развёртывания не использовался по ограничению пользователя.

Перед тиражированием для реальных клиентов требуется завершить эти проверки
на отдельном тестовом сервере. Этот релиз имеет статус release candidate.
