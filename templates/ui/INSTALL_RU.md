# Подключение помощника

Настрой OAuth-подключение MCP к этому экземпляру:
`https://<домен этого Сферы>/galactica-mcp/mcp`.
Войди своей учётной записью Сферы и подтверди разрешения.
Каталоги базовых навыков находятся в `skills/` установочного репозитория.
Права определяются текущим пользователем и ACL, а не параметрами инструмента.
