# Устройство

Каждый клиент получает отдельные PostgreSQL, Qdrant, Neo4j, тома и сеть.
Вход самостоятельный: локальные пользователи, хеши паролей, ограниченные сессии.
MCP использует OAuth authorization code с PKCE S256 и явным согласием.
Администратор создаётся локальной командой; общего пароля или пользователя по умолчанию нет.
Отзыв пользователя или его сессии прекращает доступ MCP и веб-интерфейса.
Модели включаются отдельно профилем ai; без них задачи и каноническая память доступны,
а модельная обработка и проекции ждут настройки. Ночной процесс рабочего компьютера
не входит в автоматическую серверную установку.
